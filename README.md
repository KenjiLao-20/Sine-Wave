# 📊 Interactive Sine Wave Visualization

A D3.js-powered sine wave explorer with real-time controls and interactive features.

<br>

## ✨ Features

- Adjust **Frequency** (0.5–10), **Amplitude** (0.1–1.0), and **Resolution** (20–200)
- **Hover** over the wave to see exact values
- **Preset buttons** for quick wave patterns
- **Data table** showing angle and sin(x) values

<br>

## 🎮 How to Use

1. Move any slider to update the wave in real-time
2. Hover over the curve to see coordinates
3. Click preset buttons for different waveforms

<br>

## 🛠️ Built With

- D3.js v7.8.5
- HTML5 / CSS3 / JavaScript (ES6)

<br>

## 🚀 Run

Save as `index.html` and open in any browser.
